# Your photos go here 📸

Drop your pictures in this folder (`.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`).
They show up in the gallery sorted by file name, so name them like:

    01.jpg
    02.jpg
    03.jpg

Captions come from `src/config.js` (`captions`), in the same order.
If this folder has no pictures, the gallery shows cute placeholders instead.
